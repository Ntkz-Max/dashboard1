📬 Newsletter Dashboard

![Screenshot (1181)](https://github.com/user-attachments/assets/aafc8225-75c3-4d5e-95a2-042fe7df8085)


A responsive, modular web application designed to help users create, publish, and manage newsletter messages with ease. This lightweight dashboard provides a clean UI for writing content, tracking message history, and toggling between light and dark modes — all built using pure HTML, CSS, and JavaScript.

✨ Features
✅ Responsive Dashboard Layout
Collapsible sidebar navigation with intuitive routing between Dashboard, Publish, and History pages.

🌙 Dark / Light Mode Toggle
Easily switch between dark and light themes using a built-in toggle switch.

📨 Newsletter Publishing Form
Compose and submit new messages with a simple form. Upon submission, users receive a toast notification for confirmation.

📅 Message History Table
Displays a log of published messages with IDs, content previews, and timestamps.

🧩 Modular Navbar Component
Reusable navbar loaded via JavaScript using fetch() for consistent layout across pages.
